Cloudflare Workers 프록시 — 3단계

무료 플랜으로 충분합니다. 5분이면 끝납니다.

1
Worker를 만들고 아래 코드를 붙여넣기

dash.cloudflare.com → Workers & Pages → Create → Worker → 이름 입력(예: golden-keyword) → Deploy. 그다음 Edit code에서 기본 코드를 모두 지우고 아래 코드를 붙여넣은 뒤 다시 Deploy.

2
네이버 키 5개를 Worker에 넣기

Worker → Settings → Variables and Secrets에서 추가:
NAVER_AD_LICENSE, NAVER_AD_SECRET, NAVER_AD_CUSTOMER_ID (검색광고)
NAVER_CLIENT_ID, NAVER_CLIENT_SECRET (오픈 API)
값을 넣을 때 형식을 Secret으로 고르면 대시보드에서도 다시 보이지 않습니다. 키를 여기 넣으면 이 페이지에는 키를 입력하지 않아도 됩니다.

3
주소를 이 페이지에 등록

Worker 주소 https://golden-keyword.계정.workers.dev를 위 설정의 프록시 URL에 붙여넣고 프록시 연결 테스트를 누르세요. 주소 끝 /health를 브라우저에 열어 "ad": true가 보이면 준비 완료입니다.

worker.js · 네이버 서명은 Worker가 직접 만듭니다 

      


      

        막힐 때 · 401/403이면 검색광고 키·고객ID를 확인하세요(서명은 Worker가 생성). · 브라우저에서 CORS 오류가 나면 Worker의 ALLOW_ORIGIN에 이 페이지 주소(https://kitchen2xx.github.io)를 넣거나, 파일로 열 때는 *로 두세요. · 429는 호출 한도이므로 설정의 호출 간격을 500ms 이상으로 올리세요. · 프록시에 키를 넣지 않고 이 페이지의 키를 쓰려면 그대로 두면 됩니다(브라우저가 키를 Worker로만 전달).
      

      

        보안 · Worker 주소를 아는 사람은 누구나 이 프록시로 네이버 API를 호출할 수 있습니다. ALLOW_ORIGIN과 PROXY_KEY를 꼭 함께 쓰는 것을 권합니다(이 페이지 설정의 프록시 키 칸에 같은 값을 넣으면 됩니다).
